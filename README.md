# SMARTMAP AI 🗺️

SMARTMAP AI is an interactive map coloring game developed using Python and Pygame. It uses Constraint Satisfaction Problem (CSP) and Backtracking Algorithm to solve the map coloring problem.

## Features

- Interactive Map Coloring
- AI Solver
- AI Hint
- AI Explanation
- Constraint Checking
- Score and Timer

## Technologies Used

- Python
- Pygame
- CSP
- Backtracking Algorithm

## How to Run

```bash
pip install pygame
python smartmap.py
